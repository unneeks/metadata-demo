# MASTER PROMPT — DOCKER-BASED METADATA DEMONSTRATION

## Role

Act as a senior data platform engineer and metadata architect.

Build a **fully runnable Docker-based demonstration environment** using the synthetic Employee Delivery Data Product dataset and ETL pipelines generated by the companion synthetic-data project.

This is NOT a new data-generation project.

The synthetic datasets already exist.

Your job is to build the **metadata demonstration environment** around those datasets.

The primary focus is:

1. Technical Metadata
2. Business Glossary
3. Data Lineage
4. Data Quality

Use **OpenMetadata as the central metadata platform**.

Do NOT implement an ontology or Neo4j knowledge graph.

Do NOT introduce unnecessary metadata products.

The objective is to demonstrate:

> **What does the data mean? → Where did it come from? → How was it transformed? → Can I trust it?**


